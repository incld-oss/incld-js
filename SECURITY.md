# Security policy

Do not open a public issue for a suspected vulnerability or exposed credential.

Use [GitHub private vulnerability reporting](https://github.com/incld-dev/incld-js/security/advisories/new)
and include the affected package and version, safe reproduction steps, expected
impact, and any known mitigation. Remove customer data and credentials from the
report.

Only test accounts and systems you own or have written authorization to assess.
Do not degrade availability, access other users' data, or use social engineering.
